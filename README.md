# farmOS Resource Conservation Plan

Provides resource conservation planning features for farmOS.

This module is an add-on for the [farmOS](http://drupal.org/project/farm)
Drupal distribution.

## Installation

Install as you would normally install a contributed Drupal module.

With composer:

```
composer require drupal/farm_rcp
```
