# farmOS Sustainable Land Initiative

Provides farmOS features for the
[Sustainable Land Initiative](https://www.us-ltrcd.org/sustainable-land-initiative-ec3829e).

This module is an add-on for the [farmOS](http://drupal.org/project/farm)
Drupal distribution.

## Installation

Install as you would normally install a contributed Drupal module.

With composer:

```
composer config repositories.farm_sli vcs https://github.com/farmier/farm_sli.git
composer require farmier/farm_sli
```
